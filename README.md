# Сайт Кушницького ліцею

Статичний сайт без серверної частини. Новини підтягуються зі сторінки Facebook автоматично.

## Як це працює

1. Вчитель публікує пост на сторінці ліцею у Facebook.
2. Двічі на день (або за кнопкою) GitHub Actions запускає `scripts/sync-facebook.mjs`.
3. Скрипт читає нові пости через Graph API, зберігає фото в `images/` і дописує `posts.json`.
4. Сайт (`index.html`) показує `posts.json`. Хостинг: GitHub Pages, Cloudflare Pages або Netlify, усе безкоштовно.

## Підключення Facebook (один раз)

1. Відкрийте [developers.facebook.com](https://developers.facebook.com) → **Create App** (тип Business).
2. Додайте дозволи `pages_show_list` і `pages_read_engagement`. Для читання публічних постів може знадобитися `Page Public Content Access`.
3. У **Graph API Explorer** оберіть свій застосунок, згенеруйте User token, потім обміняйте його на довготривалий (long-lived), а потім отримайте **Page access token** через запит `GET /me/accounts`. Токен сторінки, отриманий з довготривалого токена, не має терміну дії.
4. Знайдіть **ID сторінки** у «Про сторінку» (Page transparency) або у відповіді `/me/accounts`.
5. У репозиторії GitHub: **Settings → Secrets and variables → Actions → New repository secret**:
   - `FB_PAGE_ID` = ID сторінки
   - `FB_PAGE_TOKEN` = токен сторінки
6. Відкрийте вкладку **Actions → Синхронізація новин з Facebook → Run workflow**, щоб перевірити.

Токен нікому не передавайте й не вставляйте в код, лише в Secrets.

## Публікація на GitHub Pages

**Settings → Pages → Deploy from a branch → main / root.** Свій домен (наприклад, `kushnytsia-lyceum.edu.ua`) додається там само, у полі Custom domain.

## Що змінити під себе

У `index.html`: адреса, телефон, пошта в розділі «Контакти»; розклад дзвінків у масиві `BELLS`; напрямки, цифри та тексти в розділі «Про нас».

## Локальна перевірка

```bash
python3 -m http.server 8000
# відкрийте http://localhost:8000
```

Синхронізація вручну:

```bash
FB_PAGE_ID=... FB_PAGE_TOKEN=... node scripts/sync-facebook.mjs
```

## Розклад уроків і календарі класів

1. Відкрийте `data/schedule.csv` в Excel або Google Таблицях. Колонки: `клас, день, урок, предмет, вчитель, кабінет`. Вчитель і кабінет не обов'язкові. Один рядок це один урок.
2. Клас пишіть як `5-А`, день як `Понеділок`…`П'ятниця`, урок цифрою.
3. Перший рядок файлу починається з `# ЗРАЗОК`. Видаліть його, коли внесете справжній розклад. Доки він є, сайт показує позначку «зразок» і не пропонує календарі.
4. Збережіть як CSV (UTF-8) і завантажте на GitHub у те саме місце (**Add file → Upload files**, папка `data`). Автоматично запуститься «Оновлення розкладу й календарів»: воно створить `schedule.json` і файли `calendar/<клас>.ics`.
5. У розкладі класу на сайті з'являться кнопки «Додати в Google Календар» і «Додати в Apple Календар». Це підписка: коли ліцей змінює розклад, календарі в телефонах оновлюються самі (Google може відставати до доби).
6. Час дзвінків і навчальні періоди (`terms`), а також канікули (`holidays`, формат `{"from":"2026-12-26","to":"2027-01-10"}`) змінюються в `schedule.json`. Календарі не створюють уроки в дні канікул.

Локальний запуск: `node scripts/schedule-from-csv.mjs && node scripts/make-calendars.mjs`.

## Нові розділи сайту

Усі наповнюються в адмін-панелі (`/admin/`), без коду. Порожні розділи на сайті не показуються. Зараз у кожному є одна картка-приклад з позначкою «Приклад», видаліть її після першого запису.

- **Оголошення**: банер угорі сторінки (звичайне, попередження, терміново), може сам зникнути після вказаної дати. Відвідувач може його закрити.
- **Їдальня**: меню на тиждень, поточний день підсвічується.
- **Досягнення учнів**: назва, учень, клас, рівень, результат, дата, вчитель, фото грамоти й учня. Є фільтр за рівнем. Фото й дані учнів публікуйте лише за письмовою згодою батьків.
- **Кабінети й напрями**: освітня галузь, номер, відповідальний вчитель, опис, матеріальна база, фото класу й додаткові фото.
- **Пошук** (кнопка-лупа): шукає по новинах, документах, вчителях, досягненнях, кабінетах, меню та розкладу класів.
- **Форма звернень**: див. нижче.

### Форма звернень

Сайт статичний, тому для листів потрібен зовнішній безкоштовний сервіс. Підійде [Formspree](https://formspree.io) або [Web3Forms](https://web3forms.com): створіть форму, вкажіть пошту ліцею й отримайте адресу форми (Formspree) або ключ (Web3Forms). Занесіть це в адмін-панелі в «Налаштування сайту»: адреса форми та, за потреби, ключ. Доки це не зроблено, форма попросить відвідувача написати на пошту. Усі повідомлення приходитимуть на пошту ліцею, нічого не зберігається на сайті.

## Новини в Telegram і Viber

Нова новина з адмін-панелі або з Facebook автоматично надсилається в канали. Старі новини не надсилаються, лише ті, що не старші за 3 доби. Перший запуск лише запам'ятовує наявні новини.

**Telegram (працює автоматично)**
1. У Telegram знайдіть `@BotFather`, команда `/newbot`, збережіть токен бота.
2. Створіть канал і додайте бота адміністратором з правом публікації.
3. У репозиторії: **Settings → Secrets and variables → Actions → Secrets** додайте `TELEGRAM_BOT_TOKEN` (токен) і `TELEGRAM_CHAT_ID` (`@назва_каналу`, якщо канал публічний).
4. У вкладці **Variables** додайте `SITE_URL` (адреса сайту без слеша в кінці, щоб посилання в повідомленнях вели на новину).

**Viber**
Автоматична публікація в канал Viber потребує доступу до їхнього API; з лютого 2024 боти Viber створюються лише на комерційних умовах. Я не зміг підтвердити умови за документацією, тому модуль у `scripts/notify-messengers.mjs` написаний за пам'яттю й **не перевірений**: він вмикається, якщо додати секрети `VIBER_AUTH_TOKEN` і `VIBER_FROM`, а помилка не зупиняє роботу. Надійна альтернатива вже працює: у вікні кожної новини, написаної в панелі, є кнопка «Поділитися: Viber», яка відкриває Viber з готовим текстом і посиланням.

## Адмін-панель: новини, документи, фото вручну

Панель відкривається за адресою `https://ВАШ-САЙТ/admin/`. Входити потрібно через обліковий запис GitHub. Усе, що ви збережете, потрапляє в репозиторій, а сайт оновлюється за хвилину-дві.

**Що можна робити в панелі**
- **Новини**: заголовок, дата, текст, головне фото, додаткові фото, прикріплені документи, «Закріпити зверху». Такі новини змішуються з постами з Facebook за датою, а новина відкривається у вікні з повним текстом.
- **Фотогалерея**: альбоми з назвою, датою й фото. Розділ «Фото» на сайті з'являється, коли є хоча б один альбом.
- **Документи**: розділи й файли (PDF, Word тощо) або посилання.
- **Вчителі**: групи й працівники.

Пости з Facebook та ручні новини не заважають одне одному: перші живуть у `posts.json`, другі в `posts-manual.json`.

**Налаштування (один раз)**
1. У `admin/config.yml` замініть `repo` на свій репозиторій (`логін/назва`), `site_url` на адресу сайту.
2. Панель входить через GitHub, для цього потрібен безкоштовний сервіс авторизації. Найпростіше розгорнути [sveltia-cms-auth](https://github.com/sveltia/sveltia-cms-auth) на Cloudflare Workers за інструкцією в його README: створіть OAuth App у GitHub (Settings → Developer settings → OAuth Apps), де callback це адреса воркера з `/callback`, а потім додайте Client ID і Secret у змінні воркера. Адресу воркера вставте в `base_url` у `config.yml`.
3. Кожному, хто має редагувати сайт, дайте доступ до репозиторію: **Settings → Collaborators** з правом Write. Усі зміни записуються в історію з іменем автора.

**Чого панель не робить**: розклад уроків редагується файлом `data/schedule.csv`, а Facebook-пости оновлюються самі за розкладом.

## Англійська версія та тема оформлення

- Кнопка **EN / UA** у шапці перемикає мову й запам'ятовує вибір. Пряме посилання: `https://…/?lang=en`.
- Усі службові тексти, назви документів, посад і предметів розкладу перекладає словник `i18n/en.json` (ліворуч український текст, праворуч переклад). Щоб виправити або додати переклад, змініть цей файл і запустіть `python3 scripts/build.py`.
- Імена людей автоматично транслітеруються за державним стандартом. Новини залишаються мовою оригіналу (на сайті є пояснювальна примітка).
- Для подій, опитувань, меню й оголошень є необов'язкові англійські колонки/поля (`… (EN)`). Якщо їх не заповнити, показується український текст.
- **Тема** за замовчуванням слідує налаштуванню телефону (світла/темна). Кнопка у шапці перемикає: як у системі → світла → темна.

## Керування без адмін-панелі: Google Таблиця

Події, опитування, меню їдальні й оголошення можна вести у звичайній Google Таблиці. Зміни з'являються на сайті приблизно за 5 хвилин, без GitHub і без збірки.

1. Створіть Google Таблицю з чотирма вкладками й імпортуйте в них файли з папки `sheets-template/` (Файл → Імпорт → Завантаження → «Замінити поточний аркуш»): **Події, Опитування, Меню, Оголошення**.
2. Для кожної вкладки: Файл → Поділитися → **Опублікувати в інтернеті** → оберіть саму вкладку й формат **CSV** → Опублікувати. Скопіюйте посилання.
3. Вставте посилання у `site.json`, у блок `sheets` (наприклад `"events": "https://docs.google.com/…/pub?output=csv"`) і завантажте файл у GitHub один раз. Далі змінюйте лише таблицю.
4. Опитування: створіть Google Форму, скопіюйте посилання «Надіслати» в колонку «Посилання». Результати бачите у формі.

Колонки (назви можна писати українською, регістр не важливий):

| Вкладка | Колонки |
|---|---|
| Події | Дата (15.12.2026), Час, Кінець, Назва, Місце, Опис, Посилання, Назва (EN), Місце (EN), Опис (EN), Дата завершення |
| Опитування | Назва, Опис, Посилання, Приймаємо до, Кнопка, Назва (EN), Опис (EN) |
| Меню | День, Страви (через «;»), Страви (EN), Примітка |
| Оголошення | Показувати (так/ні), Тип (звичайне / важливо / терміново), Заголовок, Текст, Посилання, Текст посилання, До, Заголовок (EN), Текст (EN) |

Правила: події й опитування з минулою датою зникають самі; оголошення зникає після дати «До»; біля кожної події є кнопки «Google Календар» та «Apple / .ics». Якщо таблиця недоступна, сайт показує дані з файлів `events.json`, `polls.json`, `menu.json`, `announcement.json`, тож він не ламається. Тримайте таблицю закритою для редагування сторонніми: публікується лише її копія для читання.
